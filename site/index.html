Features

Made for mesh networks.

Browse pages, run nodes, and extend the browser over Reticulum and NomadNet.

Reticulum native

Speaks Reticulum directly through Reticulum-Go. Links, announces, and transports work over LoRa, packet radio, or IP.

Micron-first

Renders NomadNet .mu pages with a fast Go parser compiled to WASM. A document format designed for constrained links.

Extension system

Install JS or WASM plugins with per-permission grants for network, storage, and navigation. Auditable and sandboxed.

Multiple identities

Create, import, and switch between Reticulum identities. Your address book and pages travel with your keys.

Server mode

A headless binary and Docker image serve the full UI over HTTP. Run it on a VPS or a Raspberry Pi Zero W.

Runs anywhere

Desktop builds for Linux, Windows, and macOS, plus Android and iOS. Same UI, same engine, everywhere.
